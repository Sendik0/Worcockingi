# Префабы взаимодействий

Tilemap - выполняет роль препятствий по которым можно перемещаться
**Полезно для игрока ==> позволяет перемещаться по миру**
**Опасно для игрока ==> можно провалиться в пропасть**

Падение в пропасть ниже (-5) по Y приводит к: 
1. -25hp у персонажа со 100hp
2. возвращению к положению персонажа в пространстве примерно на -3 секунды
**Опасно для игрока ==> заставляет игрока действовать аккуратней**
**Опасно для игрока ==> после 4 падений персонаж "погибает"**

# Изменяемые параметры, влияющие на геймплей

**Этими параметрами можно усложнить\упростить перемещение персонажа и его выживаемость**
Max_hp
Ускорение перемещения персонажа - move_accel
Замедление перемещения персонажа - move_deccel
Максимальная скорость перемещения персонажа - move_max
Сила прыжка персонажа - jump_strength

Гравитация падения прыжка персонажа - jump_fall_gravity
