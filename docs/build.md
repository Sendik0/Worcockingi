#Настройки сборки

Единственная доступная платформа - Windows, она же является активной. Сборка содрежит единственную сцену - Laba_2
Основные настройки сборки:
Architecture - Intel 64-bit
Build and Run on - Local Machine
Compression Method - Default


#Установленные пакеты

При помощи Package Manager были установлены:
1)Пакет ассетов Simple 2D Template
2)Unity Multiplayer Center


#Структура проекта
Структура папок проекта такова:
Assets/
├── Settings/
└── IndieMarc/
    └── PlatformerDemo/
        ├── Editor/
        ├── Materials/
        ├── Prefabs/
        ├── Scripts/
        ├── Sprites/

Как можно увидеть в проекте присутствует множество ассетов: спрайты, материалы, префабы, и т.д.
