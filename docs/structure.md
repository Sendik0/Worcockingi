# Основная игровая сцена

- Представляет собой плей тест уровень с небольшой платформинг секцией

На сцене присутствуют следующие обьекты: 
1) Игрок, созданный из префаба.
2) Сетка Уровня.
3) Задний фон,состоящий из деревьев, созданный из соответствующего префаба.
4) Камера.
5) Невидимый обьект managers, реализующий скрипт для обработки ввода.
6) свет.
7) Обьекты травы, использующие соответствующий префаб.
- Обьект игрока состоит из следующих компонентов:
1) Отрисовщик Спрайта
2) Физический коллайдер
3) Отрисовщик Анимаций
4) Капсульный Коллайдер
5) Скрипты игрока.
- Через меню инспектора можно настроить спрайт игрока, его анимации, хитбокс и физическое поведение. В прикрепленных скриптах можно менять силу и время прыжка игрока, предмет в его руке, его хп, отключать/включать неуязвимость, двойной прыжок, приседание, спавн после падения и настраивать урон от него.


- Описание Скриптов:
1) CarryItem: позволяет носить предметы.
2) Character Anim: Отрисовывает Анимации игрока, в зависимости от его действий.
3) Character Hold Item: Реализует механику предмета в руке персонажа.
4) FollowCamera: Заставляет камеру следовать за игроком.
5) Lever: реализует логику работы рычагов.
6) Parallax Background: обеспечивает задний фон паралакс эфектом.
7) Player Character: отвечает за настройку механик и поведения игрока.
8) Player Controls: Обрабатывает пользовательский ввод.
9) The Audio: отвечает за воспроизведение звуков.
