## Как запустить проект
1. Клонируйте репозиторий при помощи команды git clone
2. Откройте папку проекта в unity hub
3. Откройте основную сцену
4. Нажмите play

## Управление
Движение вперед, назад - при помощи кнопок A и D
Прыжок - Space
